Como Habilitar a REST API no MikroTik RouterOS v7

O RouterOS v7 possui suporte nativo à API REST integrada ao serviço web (www ou www-ssl). Siga os 3 passos simples abaixo no terminal (Winbox ou SSH) do seu MikroTik:

Passo 1: Ativar o serviço Web do MikroTik

Certifique-se de que o serviço HTTP (porta 80) ou HTTPS (porta 443) esteja ativo:

/ip service enable www
Caso queira usar SSL seguro (HTTPS): /ip service enable www-ssl

Passo 2: Criar um grupo de leitura seguro (Recomendado)

Para máxima segurança, crie um usuário somente leitura dedicado ao monitoramento:

/user group add name=monitor-read policy=read,test,api

Passo 3: Criar o usuário de monitoramento

Defina o usuário e senha que serão usados neste painel:

/user add name=homemonitor group=monitor-read password="SuaSenhaSegura123"
Pronto! Em seguida, abra a aba Conexão neste painel e preencha com o IP do MikroTik (ex: 192.168.88.1), usuário homemonitor e a senha escolhida.
Como Configurar Notificações no Telegram

Passo 1: Criar o seu Bot no Telegram

Abra o Telegram, pesquise por @BotFather e envie o comando /newbot. Escolha um nome e um username para o seu bot. Ele responderá com o seu Bot Token (ex: 7123456789:AAH...).

Passo 2: Iniciar conversa com o seu Bot

Abra a conversa com o bot que você acabou de criar e clique em Começar ou envie /start. (Isso é obrigatório para autorizá-lo a te enviar mensagens).

Passo 3: Obter o seu Chat ID

No Telegram, pesquise pelo bot @userinfobot e envie qualquer mensagem. Ele responderá imediatamente com o seu Id numérico (ex: 123456789).

💡 Abra o modal de Conexão, cole o Token e o Chat ID, e clique em Enviar Teste no Telegram para verificar o funcionamento!
